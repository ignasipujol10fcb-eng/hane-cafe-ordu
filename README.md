# Hane Cafe — Ordu

Responsive multilingual website for Hane Cafe in Taşbaşı, Ordu.

## Included
- Turkish / English / Spanish language switcher
- Responsive mobile navigation
- Historic/cultural café presentation
- Opening hours and address
- Instagram and Google Maps CTAs
- User-provided Hane Cafe profile image
- No framework or build step: plain HTML/CSS/JavaScript

## GitHub Pages
1. Create a new GitHub repository, for example `hane-cafe-ordu`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save. GitHub will publish the site at the generated Pages address.

## Brand/source note
Business details used in the page are based on the information supplied for Hane Cafe:
- Taşbaşı, Ordu
- Historic mansion / café / events & cultural center positioning
- Weekday hours shown as 10:00–22:00
- Kesimevi Sokak No: 4, Ordu 52100
- Instagram: @hanecafeordu

The site intentionally avoids inventing a menu, prices, phone number, email address, or weekend opening hours.
